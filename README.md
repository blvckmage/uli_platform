# ULI Platform

Веб-система управления бизнесами, сотрудниками, задачами и финансовыми отчетами. Хранит данные в CSV-файлах на сервере.

## Возможности

- Авторизация и роли: главный администратор, партнер, управляющий, бухгалтер, сотрудник
- Управление бизнесами (CRUD)
- Управление сотрудниками с разграничением доступа
- Постановка задач, план/факт, статусы, комментарии, история
- Личный кабинет сотрудника (задачи на сегодня/завтра/будущие)
- Финансовые отчеты с загрузкой Excel/CSV
- Отчеты с фильтрами
- Аналитика по задачам, сотрудникам и финансам
- Уведомления внутри системы
- Адаптивный дизайн

## Локальный запуск

```bash
npm install
npm start
```

Откройте http://localhost:3000

Логин по умолчанию: **admin** / **admin123**

## Деплой на Render.com

1. Загрузите проект на GitHub.
2. Зайдите на https://render.com и нажмите **New > Blueprint**.
3. Подключите репозиторий — Render автоматически прочитает `render.yaml`.
4. Создастся web-сервис с persistent disk на `/var/data` (где будут храниться CSV).
5. Откройте URL сервиса и войдите как `admin` / `admin123` (сразу смените пароль).

Альтернатива (без disk): создайте обычный Web Service вручную, build = `npm install`, start = `node server.js`. Без диска данные сбросятся при редеплое — поэтому рекомендуется именно blueprint.

## Структура данных

CSV-файлы лежат в `DATA_DIR` (локально — `./data`, на Render — `/var/data`):

- `users.csv` — пользователи
- `businesses.csv` — бизнесы
- `tasks.csv` — задачи
- `finance_reports.csv` — финансовые отчеты
- `files.csv` — метаданные загруженных файлов
- `notifications.csv` — уведомления
- `task_history.csv` — история изменений задач
- `uploads/` — сами файлы Excel

## Переменные окружения

- `PORT` — порт (Render задает автоматически)
- `SESSION_SECRET` — секрет для сессий
- `DATA_DIR` — куда сохранять CSV (по умолчанию `./data`)
